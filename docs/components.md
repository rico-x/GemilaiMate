# Комплектующие текущей версии

- [Модули и выбранные варианты](modules.csv): ESP32-S3 N8R8, LilyGo T-RGB 2.1, MAX31855, XDB401 0-1,6 МПа /0,5-4,5 В, изолированная термопара, RobotDyn Standard, ADS1115, один TXS0102 для I2C, SSR High5V. Ссылки - ориентиры конкретных вариантов; наличие, отзывы, цену и полученную ревизию проверять перед покупкой. Снимки корзин и старые цены не включены.
- [SMD BOM](../hardware/carrier/manufacturing/BOM-SMD.csv): 7×10 кОм, 1×1,2 кОм, 4×1 кОм, 1×0 Ом; 6×100 нФ X7R 50 В, всё 0805; U3 SN74LVC1G17DBVR SOT-23-5. Купить с запасом. Выводные пассивы к этим посадочным местам не подходят.
- [THT BOM](../hardware/carrier/manufacturing/BOM-THT.csv): U2 SN74AHCT125N DIP14, два гнезда по 22 с подходящей высотой, остальные разъёмы P2,54 и перемычки JP1/JP3.
- Для первого стенда: внешний заводской изолированный 5 В /2 А, ограничение тока, генератор импульсов 0-5 В, осциллограф/логический анализатор. Для крепления - изолирующий держатель и разгрузка жгутов.

Природа штатных кнопок, требуемый ток SSR, силовой корпус/БП, подходящие для горячей воды фитинги/трубки/уплотнения и размеры жгутов требуют измерений. Поэтому полного закрытого списка покупок для установки в машину пока нет. IRM-10-5 и HLK - модули для PCB, сами по себе не решают безопасный монтаж сети; для стенда используется готовый внешний БП.

Для shield v0.2.2 активные модули и SMD те же; набор гнёзд отличается: [BOM-THT shield](../hardware/shield/manufacturing/BOM-THT.csv). Нужны ответные штыри трёх вставных модулей, прижимы и управляющие жгуты: 4 жилы RobotDyn, 3 жилы SSR. Штатная входная клемма SSR сохраняется. Для сравнения двух вариантов допустимо переставлять один комплект модулей.
