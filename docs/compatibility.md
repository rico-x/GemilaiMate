# Совместимость Compact с GaggiMate

Дата сверки: 03.11.2026. **Ни одна строка аппаратного теста пока не имеет статуса passed.**

Compact использует определение Pro PCB Rev 1.1 (ID=4). В закреплённой GaggiMate v1.9.0 этот профиль и Pro LEGO (ID=3) имеют одинаковые GPIO, полярности и возможности. Смена ID уточняет аппаратный профиль и отличает Compact от старого shield; новых функций сама по себе она не добавляет. Делитель изменён с 10 кОм / 1,2 кОм на 10 кОм / 1,58 кОм: около 450 мВ, середина окна ID=4. В обеих прошивках ID должен определяться на физической плате.

| Пара / функция | Проверено по файлам | В железе |
|---|---|---|
| GemilaiMate controller + display, carrier/shield | Старые GPIO 15/16 сохранены; отдельная цель | Не проверено |
| GemilaiMate controller-compact + display | ID=4; Alba 43/44; 8-MB карта, N16R8 | Не проверено |
| GaggiMate v1.9.0 controller + display | Профиль Pro PCB Rev 1.1; сверены GPIO и параметры памяти | Не проверено |
| GaggiMate master b78beee | Исходники закреплены для сравнения, это не релизная гарантия | Не проверено |
| ROM USB, BOOT/RESET, Flash/PSRAM | Предусмотрены по документации Espressif | Не проверено |
| ADS1115, MAX31855, кнопки, ZC/выходы | Схема и распиновка; номинальные модули | Не проверено |
| PCA9634 + VL53L0X / внешняя Alba | Разведён отдельный I2C 43/44; PCA адрес 0x00 | Не проверено |
| Возврат официальный → собственный без перепайки | Требование: фиксированная распиновка, без UART-моста | Не проверено |

Последний стабильный релиз оригинала при сверке — v1.9.0, commit `43d2a7ba2299c196fd67c001f455985e07e57a49`; master — `b78beee4dbcc1cd59946256f05e5cafa5450ec60`. Источники и контрольные суммы файлов приведены в [sources.json](../hardware/shield-compact/sources.json). Новые upstream-изменения автоматически не импортируются.

Нужны согласованные controller/display одного проекта и версии. BLE-идентификаторы GemilaiMate отличаются; смешанные пары не поддерживаются этим заявлением. Разметка NVS/настройки могут различаться: сохранить дампы и заново настроить сопряжение. Совпадение GPIO не переносит защитные изменения собственной прошивки в официальный BIN.

Полная обратная совместимость будет подтверждена только после нескольких циклов переключения на первой собранной плате с проверкой всех функций. Номиналы датчиков, внешние модули и разъёмы при этом должны оставаться теми же. Ни ERC/DRC, ни успешная сборка не доказывают эту совместимость.

Требования и порядок испытаний: [Compact Shield](compact-shield.md). Состояние остальных вариантов: [validation.md](validation.md).
