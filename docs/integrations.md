# Сетевые интерфейсы текущей версии

В исходниках доступны локальный Web UI, WebSocket API, MQTT и HomeKit. Имя точки доступа и mDNS - GemilaiMate / gemilaimate. Их работа на реальных модулях ещё не подтверждена. Старое расширение Home Assistant от другого проекта не заявлено совместимым: интерфейсы адаптации нужно проверить отдельно. Встроенная загрузка прошивок из интернета отключена; обновление - через USB из согласованного релиза GemilaiMate.
