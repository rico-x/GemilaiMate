# План испытаний

**Все аппаратные пункты пока не выполнены.** Начать с низковольтного стенда: внешний заводской изолированный 5 В /2 А, силовые нагрузки и сеть кофемашины отключены. Нужны источник импульсов 0-5 В, осциллограф/логический анализатор и подходящий прибор для давления.

- [ ] До MCU: нет КЗ 5 В/GND, 3,3 В/GND; R1=10 кОм, R2=1,2 кОм; U2/U3 и питание ориентированы правильно.
- [ ] Обе ESP32 отдельно прошиваются текущей v0.1.0; загружаются дисплей и контроллер, работает BLE-связь. Фактические строки версии проверить в логах/интерфейсе.
- [ ] ID=3 в 10 включениях из 10. При неверном ID управляющие выходы не включаются.
- [ ] На включении/сбросе/выключении GPIO9, GPIO10, J6.3, J10.3 остаются LOW.
- [ ] Генератор на J5.3 относительно J5.2, 0-5 В: отдельные 50/60/100/120 Гц квалифицируются, GPIO9 следует 0/50/100%. Отрицательные и >5,5 В импульсы не подавать.
- [ ] Команда 0 даёт LOW без ожидания ZC. Потеря ZC при HIGH отключает помпу и фиксирует код 7 до перезапуска; возвращение импульсов не запускает её. Порог 30 мс, период проверки 5 мс; фактическую задержку измерить под нагрузкой. Около 40 мс - цель стенда, не готовая гарантия.
- [ ] Запрос мощности без ZC даёт фиксируемую ошибку после порога 250 мс плюс период таймера/планировщик; около 260 мс - цель измерения.
- [ ] Потеря дисплея отключает управление после 20 с плюс период цикла/планировщик. Ошибка ZC не заменяется восстанавливаемым таймаутом.
- [ ] Многочасовой реальный BLE-обмен без ложных `Ping timeout detected`. Host-симуляция времени не заменяет этот тест.
- [ ] Сухие кнопки: по одному событию на нажатие, 100 нажатий без пропусков; нет ложных событий при ZC/PSM.
- [ ] MAX31855: корректная температура, отключение термопары приводит к отключению управления. Термопара должна иметь проверенную изоляцию от сетевых цепей машины.
- [ ] Датчик уровня VL53L0X (если установлен): без него контроллер стартует без уровня воды; с ним Web UI показывает расстояние, после калибровки бака — уровень в процентах.
- [ ] ADS1115 0x48, A0: при шкале 16 бар контрольные 0,5/2,5/4,5 В дают 0/8/16 бар после установления фильтра; подтвердить калибровку и питание датчика.

До машины отдельно выяснить электрическую природу штатных кнопок, входной ток SSR и гарантированные HIGH/LOW AHCT125 при фактической нагрузке, форму ZC, конструкцию/изоляцию/температуру силового узла, защитное отключение и паспорта гидравлики на горячую питьевую воду, температуру и давление. Фитинги и уплотнения нельзя окончательно выбирать без геометрии резьбы/посадки.

На машине затем нужны осциллограммы J5.3/GPIO21 при помпе, 30-50 проливов со счётчиком ложных аварий, проверка давления/кнопок и крепления. Строгость PumpPSM пока сохранена. Пропуск одного фронта при 50/60 Гц даёт 40/33,3 мс, превышая сторож 30 мс: смягчать обработку без отдельного анализа нельзя. Программная защита не заменяет независимое физическое отключение при зависании MCU.
