# Проверки GemilaiMate v0.1.0

**Физическая воспроизводимость пока не подтверждена:** PCB не изготовлена/не собрана, USB-запись, BLE и работа в Gemilai не испытывались. Проверки файлов не заменяют стенд.

Фактически пройдены: **ERC 0, DRC 0, unconnected 0, parity 0; 19 host-сценариев; 6 тестов flasher; 42 дополнительных теста Unity**. Семь сетевых тестов пропущены. Обе прошивки, Web UI и LittleFS собраны; 9 размеров/SHA-256 BIN сверены. Два изменённых UI-компонента прошли ESLint. 13 GPIO/29 цепей совпадают. Медь PCB совпадает с проверенной разводкой до переименования; изменены имя/маркировка/метаданные. После v0.1.0 к посадочным местам добавлены только 3D-модели для визуализации: Gerber и сверловка из текущей PCB совпадают с файлами производства, ERC/DRC повторены с нулевым результатом. Сборка выполнена до создания Git-репозитория, из самостоятельного дерева.

[Независимый запуск GitHub CI](https://github.com/rico-x/GemilaiMate/actions/runs/40653238272) также завершён успешно: установка зависимостей, host-тесты, сборки двух ESP32/Web UI/FS и дополнительные native-тесты.

Текущая программа проверок: сборки controller/display и Web UI, LittleFS из текущих исходников, заголовки и хеши BIN, 14 host-сценариев PumpPSM/DigitalInput, 5 PingWatchdog, 6 тестов flasher, ERC/DRC с parity, 13 GPIO/29 цепей, проверка производственного экспорта и визуальный просмотр PDF/превью. Фактические результаты сохраняются в `validation.json` и текущих JSON рядом с PCB.

Сторож помпы: stop(0) немедленно опускает GPIO; потеря ZC при запросе мощности фиксирует аварию до перезапуска. Таймаут BLE сохраняет 20 с, метка пинга атомарна и читается до часов с перепроверкой устаревшего снимка. Host-тест моделирует сутки обмена, не выполняет суточный прогон ESP32.

ERC проверяет интерфейсную схему, не внутренние схемы купленных модулей. DRC действует с правилами проекта; пропущенные категории перечислены в ignored_checks отчёта. Не исключались соединения, замыкания, зазоры и parity. Габарит/распиновка клона, высота, SSR, ZC, кнопки, шум давления, вибрации, изоляция, силовая часть и гидравлика остаются предметом [стенда](bench.md). До заказа сверить шаблон и просвет ≥5 мм.

## Shield v0.2, 28.10.2026

Второй активный прототип, hardware/shield, 90×75 мм. Свежие ERC = 0, DRC = 0, unconnected = 0, schematic parity = 0. Сверены 13 GPIO с неизменённой прошивкой v0.1.0, совпадение SMD BOM с carrier и CPL новых положений фильтра давления. Компоновка и 3D номинальные. Реальные клоны, межрядье TXS, доки RobotDyn/SSR, механический держатель, корпус машины и аппаратные испытания ещё не проверены. Отчёты carrier относятся к carrier, отчёты shield — к shield. Старый GitHub CI прошивки не выдаётся за испытание новой платы.

Дополнительно проверены реальные Gerber: у всех 121 PTH-площадок shield открыта паяльная маска с обеих сторон, переходы тентированы. Новая проверка выявляет закрытые маской выводные площадки, даже если DRC не сообщает об ошибках. Проверен и свежий запуск генератора посадочных мест.
