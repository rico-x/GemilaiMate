# Compact: производственный комплект прототипа

Не отправлять в производство как проверенный серийный проект. Нужны независимая проверка схемы/BOM, реальные размеры модулей и согласование стека/USB с фабрикой. Аппаратных испытаний нет.

Gerber ZIP: четыре слоя, без платы-панели и без заказа монтажа. BOM: количества на 1/5 PCB; DNP не устанавливать. Жгуты HARNESSES рассчитаны на одну кофемашину, не на пять. SMD CPL содержит центры компонентов и вид сверху; у WROOM учтён сдвиг 0,75 мм от начала его посадочного места. Модуль включён в SMD несмотря на тепловые PTH-площадки; сторона и повороты требуют проверки в предпросмотре конкретного сборщика. Выбор MPN-примеров проверить у поставщика по полному артикулу; не подменять DCT/DCU/X2SON. Гнёзда модулей и JST PH паять со стороны, указанной в BOM-THT.

Все резисторы 0603, малые конденсаторы 0603, 10uF — 1206. Основной модуль WROOM требует надёжной пайки центральной земли. Нужен ручной контроль сборки; один паяльник не гарантирует пайку скрытого контакта.
