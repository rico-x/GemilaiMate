# Current release artifacts

Download the v0.1.0 prototype assets from https://github.com/Rico-X/GemilaiMate/releases/tag/v0.1.0 after signing in to the private repository. Local builds are written here by `python tools/build_release.py`. These generated binaries are not committed as alternate source snapshots.

Hardware assembly, USB flashing and operation in a Gemilai have not been performed. Follow docs/bench.md before connecting machine loads.
